# CS 104 - Create a Welcome Screen

In this assignment, you will learn more about how to use the `print` function.


## Instructions

### Clone (download) your repo from GitHub

- Copy the SSH link from GitHub
- Open a new terminal
- `git clone <REPO_LINK>`

### Complete the assignment

- Open the repo in VS Code
- Open **welcome.py**
- Follow the instructions in the TODO comment
- Run your code: `py welcome.py`
- Your completed assignment should print out the following:
    ```
    ==================================================
                        VitalLink
      Your partner in smarter, connected healthcare
    ==================================================

    Welcome!
    We're excited to support you on your health journey.

    With VitalLink, you can stay connected with providers,
    track important health information, and access tools
    designed to help you live well every day.
    ```

### Test your assignment

- Install the required libraries: `pip install -r requirements.txt`
- Run the tests to check your work: `pytest`
- If you get a red **failed** message, read the error messages and fix **welcome.py** accordingly
- If you get a green **passed** message, you have completed the assignment correctly

### Submit your assignment

Push your changes to GitHub:
- `git add .`
- `git commit -m "changed the README.md file"`
- `git push`
